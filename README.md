# SLA Dashboard

Робочий час налаштовується через змінні середовища або Streamlit secrets:

```toml
WORK_START = "11:00"
WORK_END = "19:00"
LUNCH_START = "14:00"
LUNCH_END = "15:00"
```

Також підтримується запис лише години, наприклад `WORK_START = 11`. Змінні
середовища мають пріоритет над однойменними значеннями в Streamlit secrets.

## Відсікання аномалій

Аномально довгі угоди не враховуються в середньому, медіані, максимумі
та графіках, але лишаються в таблиці угод (колонки `Taken Anomaly`,
`Called Anomaly`) і в окремому списку «Аномалії».

Поріг рахується автоматично для всього відділу окремо для TAKEN і CALLED:
75-й перцентиль + 3 × міжквартильний розмах (метод Тʼюкі), але не менше
30 хв. Якщо угод менше 10, нічого не відсікається.

У боковій панелі відсікання можна вимкнути або задати поріг вручну (у хвилинах).
